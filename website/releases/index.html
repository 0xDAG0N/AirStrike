Release overview

Airstrike v0.0 is the very first working build of the platform. It marks the point where the tooling, packaging, and documentation all line up so everyone can pull the code, inspect it, and begin experimenting.

  • First tagged drop of the Airstrike codebase.
  • Source archives generated directly from the signed Git tag so the code you read is the code we built.
  • Baseline for testers and contributors to file issues and help prioritize the roadmap.

Expect rough edges—this is a pre-release snapshot intended to spark feedback. File issues, send patches, and tell us what you want stabilized first.

Stay updated

The easiest way to hear about new Airstrike builds is to follow the repository directly. GitHub handles the notifications, and you only get pinged when a new tag ships.

  1. Open the Airstrike repository.
  2. Use the Watch menu → Custom → enable Releases only.
  3. Optionally pull the Atom feed into your reader for archival tracking.
